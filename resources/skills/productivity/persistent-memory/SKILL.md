# Persistent Memory

Use this skill when a user asks the agent to remember something, corrects a stable behavior, or reveals a durable project/environment fact.

## Workflow

1. Decide whether the fact is durable. Prefer preferences, project conventions, environment details, and repeatable workflow lessons.
2. Choose `user` for identity, preferences, communication style, and habits.
3. Choose `memory` for project facts, local setup, tool quirks, and completed workflow notes.
4. Use the `memory` tool with `add` or `remove`. If a fact needs editing, remove the old entry and add the corrected one.
5. Keep each entry short; avoid raw logs, long code, and one-off task context.
