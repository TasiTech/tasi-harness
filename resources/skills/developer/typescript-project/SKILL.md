# TypeScript Project

Use this skill when working on TypeScript codebases.

## Workflow

1. Inspect package scripts and tsconfig files.
2. Prefer strict types over `any`.
3. Add unit tests for reusable logic.
4. Run `npm run typecheck` and `npm test` when terminal access is enabled.
5. Keep Electron main, preload, renderer, and shared types separated.
