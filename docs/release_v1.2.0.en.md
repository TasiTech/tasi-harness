# Tasi Harness 1.2.0 Release Notes

[English](release_v1.2.0.en.md) | [简体中文](release_v1.2.0.zh-CN.md)

Release date: 2026-04-28

## Highlights

1. Fixed Markdown table rendering stability, including mixed table/paragraph layout and trailing URL punctuation handling.
2. External browser preview now auto-closes after task/session completion.
3. Added a stop button behavior aligned with in-chat running state.
4. Improved Skill Marketplace display and retrieval UX (clearer cards, badges, debounced search).
5. Added session document upload for chat context (e.g., PDF) without entering Personal Knowledge Base.
6. Added DeepSeek v4 model options: `deepseek-v4-flash`, `deepseek-v4-pro`.
7. Verified scheduled task notifications and added WeChat notifications alongside email.
8. Added token usage display (last + cumulative) in `M` units.
9. Expanded multi-format document interpretation, including Office OpenXML and PDF session context ingestion.

## Packaging

- App version bumped to `1.2.0`.
- Existing installer scripts remain compatible.
