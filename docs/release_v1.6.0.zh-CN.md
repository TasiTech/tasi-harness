# Tasi Harness 1.6.0 发布说明

[English](release_v1.6.0.en.md) | [简体中文](release_v1.6.0.zh-CN.md)

发布日期：2026-08-04

## 版本摘要

Tasi Harness 1.6.0 将桌面智能体从单轮对话进一步推进到可持续运行的工作台：新增实时语音、智能体循环、工具注册、技能市场、定时任务、邮件通知和沙箱执行能力，并强化 Omni 模型接入与主题系统。

## 主要更新

1. 新增实时语音模式：支持通过 Omni / Realtime 模型进行实时语音对话，并可在实时模式中创建后台任务。
2. 增强智能体循环：后台任务可持续执行工具调用、收集结果、更新任务卡状态，并在任务完成后触发新的模型回复。
3. 新增工具注册体系：工具调用、工具结果与轨迹展示更加清晰，便于区分实际执行步骤和模型推理过程。
4. 新增技能市场：支持浏览、安装和管理技能，为重复工作流提供更容易扩展的能力入口。
5. 新增定时任务：支持创建、运行和管理后台任务，适合周期性检查、自动处理和异步长任务。
6. 新增邮件通知：后台任务可在完成后通过邮件发送通知，减少长时间等待和手动轮询。
7. 新增沙箱执行：为工具运行提供更明确的执行模式和安全边界，降低本地文件与命令操作风险。
8. 扩展 Omni 提供商：增加 Qwen Omni、SoildAPI Omni 预置，并为兼容 OpenAI Realtime 协议的提供商预留接入路径。
9. 增强主题系统：新增科技蓝主题、DreamSkin 主题库浏览与一键安装、主题包导入、背景图显示和字体亮度调节。
10. 优化桌面体验：隐藏原生菜单栏和标题栏，使用更沉浸的应用窗口，并修复麦克风选择、背景图、任务卡闪烁和实时模式重复回复等界面问题。

## 适用场景

- 需要边说边让智能体执行后台任务，例如实时讨论、拆解工作、持续跟进工具结果。
- 需要把复杂任务放入后台运行，并在完成后让模型基于结果继续给出回复。
- 需要通过技能市场安装工作流能力，而不是手动维护本地脚本。
- 需要定时处理信息、发送提醒、执行检查或运行周期性自动化。
- 需要接入不同厂商的 Omni / Realtime 模型，尤其是 Qwen、OpenAI 兼容协议和预留的 SoildAPI 服务。
- 需要通过 DreamSkin 或自定义主题包快速改变桌面工作台视觉风格。

## 稳定性与体验改进

- 修复实时模式中一次用户问题可能产生两次回复、两个重复后台任务的问题。
- 后台任务完成后，任务卡会闪烁 3 次作为完成提示。
- 后台任务轨迹面板会自动滚动到最新内容。
- 轨迹面板聚焦工具请求和工具结果，推理过程保留在任务卡的推理区域中。
- 修复麦克风列表中文字和下拉符号重叠的问题。
- 优化自定义主题背景图在侧栏、主区和实时模式中的显示效果。
- 增加字体亮度调节，缓解部分主题文字偏暗的问题。

## 兼容性说明

- SoildAPI Omni 当前作为预置提供商加入，协议按 OpenAI Realtime 兼容路径实现；服务上线后仍需要按实际接口做联调。
- Omni 模型能力取决于各提供商实际支持的 Realtime / 语音 / 多模态能力。
- DreamSkin 主题安装依赖 `dreamskin.cc` 及其 API 可用性；离线场景仍可使用本地主题包导入。
- 沙箱执行会影响部分需要直接访问系统资源的工具，必要时可切换执行模式或调整安全设置。
