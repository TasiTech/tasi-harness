# Tasi Harness 1.6.0 发布说明

[English](release_v1.6.0.en.md) | [简体中文](release_v1.6.0.zh-CN.md)

发布日期：2026-08-04

## 版本摘要

Tasi Harness 1.6.0 聚焦两件事：实时语音模式和主题设置。这个版本让桌面智能体可以进入更自然的实时对话，同时把主题导入、DreamSkin 主题库、背景图和字体亮度调节整理成更完整的视觉定制体验。

## 主要更新

1. 新增实时语音模式：支持通过 Omni / Realtime 模型进行双工语音对话，适合边讨论边推进任务。
2. 支持实时模式创建后台任务：复杂工作可以从实时对话中转入后台执行，减少语音会话中的等待。
3. 后台任务完成后回传 Omni：任务完成结果会发送给 Omni 模型，由模型基于结果继续给出新的回复。
4. 修复实时模式重复回复：解决一个用户问题可能产生两次回复、两个重复后台任务的问题。
5. 优化实时任务反馈：后台任务完成后任务卡会闪烁 3 次，并自动滚动到最新任务活动。
6. 调整实时轨迹展示：轨迹面板聚焦工具请求和工具结果，推理过程保留在任务卡的推理区域中。
7. 扩展 Omni 预置：增加 Qwen Omni 模型选项，并加入 SoildAPI Omni 预置提供商，按 OpenAI Realtime 兼容协议预留接入。
8. 增强主题设置：新增科技蓝主题，采用半透明蓝色基色和亮蓝绿色强调色。
9. 支持 DreamSkin 主题库：主题设置页可以浏览 `dreamskin.cc/gallery` 的主题，并一键下载安装到本地。
10. 改进主题包体验：支持导入主题包、显示背景图、优化侧栏和实时模式背景渲染，并增加字体亮度调节。

## 适用场景

- 希望用语音和智能体实时讨论，同时让复杂任务转入后台执行。
- 希望任务完成后不只是显示结果，而是让 Omni 模型基于结果继续回复。
- 希望接入 Qwen Omni、OpenAI Realtime 兼容服务，或提前预置 SoildAPI Omni。
- 希望通过 DreamSkin 或本地主题包快速更换工作台视觉风格。
- 希望改善主题中文字偏暗、背景图不明显或侧栏看不到背景的问题。

## 体验改进

- 修复麦克风列表中文字与下拉符号重叠的问题。
- 优化自定义主题背景图在侧栏、主区和实时模式中的显示效果。
- 修复导入主题后背景图不显示的问题。
- 增加字体亮度调节，降低低对比度主题的阅读压力。
- 隐藏原生菜单栏和标题栏，使应用窗口更沉浸。

## 兼容性说明

- SoildAPI Omni 当前作为预置提供商加入，服务上线后仍需要按实际接口做联调。
- Omni 能力取决于各模型提供商实际支持的 Realtime、语音和多模态能力。
- DreamSkin 主题安装依赖 `dreamskin.cc` 及其 API 可用性；离线场景仍可使用本地主题包导入。
- 主题字体亮度会影响主文字、次级文字和弱提示文字，但不会修改主题包原始文件。
