[English](release_v1.1.0.en.md) | [简体中文](release_v1.1.0.zh-CN.md)

Release date: 2026-04-04

## Summary

Version 1.1.0 established the baseline desktop agent architecture for Tasi Harness:

- Hermes-style agent loop orchestration in a TypeScript/Electron runtime
- Browser automation with embedded and external preview modes
- Local-first personal knowledge base without mandatory embedding/vector database
- Local memory, skills, session persistence, and scheduled task foundation
- Conservative security defaults (context isolation, workspace-bound file access, terminal disabled by default)
