# Tasi Harness 1.4.0 发布说明

[English](release_v1.4.0.en.md) | [简体中文](release_v1.4.0.zh-CN.md)

发布日期：2026-05-14

## 主要更新

1. 增加流式输出：对话回复支持边生成边显示，减少长回答、长工具流程和命令行对话中的等待感。
2. 增强多模态输入：面向支持多模态能力的模型，增加图片和视频输入支持，便于进行截图分析、图像理解、视频素材说明和多媒体上下文问答。
3. 增加图文文档写作能力：支持围绕文字、图片和文档素材组织内容，生成更适合报告、说明文档、方案稿和知识整理的图文型输出。
4. 增加 UI 设计技能：内置 UI 设计相关 skill，用于产品界面、网页、仪表盘和交互方案的设计推理与实现辅助。
5. 增加技能优化功能：支持根据会话执行结果和失败信号分析现有技能，并对 skill 工作流进行针对性优化，提升重复任务的稳定性。
6. 增强微信对话能力：微信对话支持上传文档、上传图片，并支持将生成文件回传给用户，方便在移动端完成资料处理和文件交付。

## 适用场景

- 长文本写作、调研总结和代码解释可以更快看到生成过程。
- 图片、视频、文档混合输入的任务可以放在同一轮对话中处理。
- 需要生成带图片、表格、结构化段落的报告时，可以直接使用图文文档写作能力。
- UI/UX 设计、页面改版和产品原型任务可以调用 UI 设计技能获得更稳定的设计建议。
- 经常复用的自动化流程可以通过技能优化功能持续改进。
- 微信侧可以承担更多轻量办公任务，例如收文件、分析图片、生成文档并回传。

## 兼容性说明

- 图片和视频输入依赖所选模型提供方是否支持对应多模态能力；不支持多模态的模型仍按文本对话处理。
- 图文文档写作和文件回传能力依赖当前会话可访问的文件工具、导出工具和微信连接状态。
- 技能优化会尽量保持变更范围聚焦在相关 skill，不会自动扩大到无关技能。
