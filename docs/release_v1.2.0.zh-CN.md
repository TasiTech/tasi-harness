# Tasi Harness 1.2.0 发布说明

[English](release_v1.2.0.en.md) | [简体中文](release_v1.2.0.zh-CN.md)

发布日期：2026-04-28

## 主要更新

1. 修复 Markdown 表格显示稳定性问题，优化表格与段落混排，以及 URL 末尾标点链接边界。
2. 外部浏览器预览支持在任务/会话完成后自动关闭。
3. 增加对话停止按钮行为，与对话执行中状态一致。
4. 优化技能市场展示与检索体验（卡片信息、来源标识、检索防抖）。
5. 增加会话文档上传对话能力（如 PDF），仅用于当前会话上下文，不进入个人知识库。
6. 新增 DeepSeek v4 模型选项：`deepseek-v4-flash`、`deepseek-v4-pro`。
7. 完善定时任务通知链路，支持邮件与微信通知。
8. 增加 Token 使用量显示（本次 + 累计），按 `M` 单位展示。
9. 增强多格式文档解读能力，支持 Office OpenXML 与 PDF 会话上下文解析。

## 打包说明

- 应用版本升级至 `1.2.0`。
- 现有安装包脚本保持兼容。

## 归档

- 上一版本发布说明：`docs/release_v1.1.0.en.md` 与 `docs/release_v1.1.0.zh-CN.md`。
