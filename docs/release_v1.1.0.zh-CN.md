# Tasi Harness 1.1.0 发布说明（归档）

[English](release_v1.1.0.en.md) | [简体中文](release_v1.1.0.zh-CN.md)

发布日期：2026-04-04

## 版本摘要

1.1.0 版本建立了 Tasi Harness 桌面智能体的基础能力：

- 在 TypeScript/Electron 运行时中实现 Hermes 风格 Agent 循环
- 提供内嵌与外部模式的浏览器自动化能力
- 提供本地优先的个人知识库能力（不强依赖 embedding/向量库）
- 建立本地记忆、技能体系、会话持久化与定时任务基础
- 采用偏保守的安全默认配置（context isolation、工作区边界、终端默认关闭）

此文档用于版本历史归档。当前版本能力与改进请参考 v1.2.0 发布说明。
